### `CanvasDrawingSession.Clear(Rect, Color)` does not exist in Win2D 1.21
The handoff's risk #1 resolved *before* wasting a build: `Win2D.win81.1.21.0` exposes only
`Clear(Color)` and `Clear(Vector4)` — verified in
`Phirura/packages/Win2D.win81.1.21.0/bin/Phone/arm/Microsoft.Graphics.Canvas.xml` (the XML doc file
is the authoritative overload list for this fork; grep it, don't guess). A rect clear would have
wiped the whole carrier. Replaced with a true region replace:
`target.Blend = CanvasBlend.Copy; DrawImage(...); target.Blend = CanvasBlend.SourceOver;`
(`CanvasBlend` = SourceOver/Add/Min/Copy; `Blend` is settable). Compiles clean.
